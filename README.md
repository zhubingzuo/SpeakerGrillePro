# v27.4 — 3Dconnexion / SpaceMouse 安全安装版

本版修复了“一键安装后 3Dconnexion 3D 鼠标在 SOLIDWORKS 中失效”的问题。旧安装器以管理员权限运行后，会直接启动 SOLIDWORKS，导致 SOLIDWORKS 继承管理员权限，而通常运行的 3DxWare/3Dconnexion 驱动仍是普通用户权限。Windows 的权限隔离会阻止两者通信。

**v27.4 改动：**
- 安装器不再自动启动 SOLIDWORKS；安装后请从平常的快捷方式正常启动。
- 安装前若检测到 SOLIDWORKS 正在运行，会提示先关闭，不会强制结束进程。
- 不再删除任何其他/旧插件的 SOLIDWORKS Add-in 注册项，只注册 SpeakerGrillePro 自己的 GUID。
- 保留 v27.3 的漂亮同心声波算法、最小孔间肉厚保护和新版喇叭图标。

# SpeakerGrillePro v27.3 — 工具栏喇叭图标美化版

- 插件的喇叭孔生成算法与参数逻辑未改动。


## v27.3 修复：圆孔 - 同心声波严格对称

针对“圆孔 - 同心声波”在圆角矩形区域中左右孔数不同、边缘孔不镜像的问题，本版做了两层修复：

- 每一圈的孔数强制取为 **4 的倍数**，并保留交替半步相位，因此完整圆环关于水平轴和垂直轴都严格镜像对称。
- 真实 Face 边界过滤时，对每个同心声波孔同时检查它的四个镜像位置；只要任一镜像位置不能完整落在实体表面，该组镜像孔就一起剔除，避免边界容差造成“单边多一个孔”。
- 修复仅针对第 7 种“圆孔 - 同心声波”，其它孔型的生成逻辑不变。

你截图中的 80 × 38 mm、圆角 16 mm、节距 3.2 mm 这类参数会按选定中心点保持左右/上下成对对称。

## v27 新增：静默启动

- SOLIDWORKS 启动并自动加载插件时，**不再弹出“插件已成功加载”提示窗口**。
- CommandManager 创建异常或 ConnectToSW 加载异常也不再在启动阶段弹出模态窗口，诊断信息写入 `bin\SpeakerGrillePro_runtime.log`。
- 用户主动点击“生成喇叭孔”后的参数错误、生成错误、孔数量过大确认等交互提示仍然保留，不影响正常使用。

## 本版新增

在 v25 稳定基线上新增第 8 种专用孔型：

**“圆形渐变 - 六角错列连续孔径（推荐）”**

该模式严格实现：

- 圆形生成区域
- 六角 / 三角错列圆孔网格
- 中心到外围连续孔径渐变
- 默认且强制不跳孔
- 完整圆孔不会越过用户给定的圆形区域边界
- 仍然进行真实 Face 边界过滤
- 自动 Cut-Extrude 与原稳定切除流程保持不变

## 连续渐变算法

专用模式不再使用“中心 / 中间 / 外围”三档突变。

- `中心孔特征尺寸` = 圆心处最大孔径
- `外围孔特征尺寸` = 圆周附近最小孔径
- `中间孔特征尺寸` 在该模式下停用
- `中心区域比例 / 中间区域比例` 在该模式下停用
- `开始跳孔比例 / 边缘跳孔率` 在该模式下停用，且代码层强制跳孔率为 0

孔径使用余弦缓动连续插值：中心和外围的变化都比较柔和，不会出现明显的三层色带。

## 推荐首测参数

```text
孔型：圆形渐变 - 六角错列连续孔径（推荐）
圆形区域直径：60 mm
孔中心距：3.0 mm
中心孔特征尺寸：2.2 mm
外围孔特征尺寸：1.0 mm
水平偏移：0 mm
垂直偏移：0 mm
```

如果圆形区域更大，可适当把中心距提高到 3.2~3.5 mm；如果想更细腻，可将中心距降至 2.6~2.9 mm，但孔数会明显增加。

## 其他功能

原 v25 的 7 种孔型全部保留：

1. 圆孔 - 六角错列渐变
2. 蜂窝 - 紧密六边形
3. 圆孔 - 方阵
4. 方形孔
5. 菱形孔
6. 三角孔
7. 圆孔 - 同心声波
8. 圆形渐变 - 六角错列连续孔径（新增）

其他 7 种样式仍可选择圆角矩形区域或圆形区域。

## 使用方法

1. 在目标平面建立二维草图点。
2. 选中草图点。
3. 点击“生成喇叭孔”。
4. 孔型选择第 8 项“圆形渐变 - 六角错列连续孔径（推荐）”。
5. 输入圆形区域直径、中心孔径、外围孔径和节距。
6. 点击“生成”。

## 安装

解压后直接运行：

```text
一键安装.bat
```

## v27.3 同心声波优化

- “圆孔 - 同心声波”改为连续平滑孔径过渡，消除明显的三级孔径分界。
- 每个完整圆环优先使用 4 的倍数孔数，保持水平/垂直双轴对称并改善视觉节奏。
- 新增“同心声波最小孔间肉厚”参数，默认 1.20 mm。
- 最小肉厚同时约束同一圆环相邻孔以及相邻圆环之间的实体连接，不允许为了增加孔数而突破该安全值。
- 参数输入硬下限 0.80 mm；塑料注塑件建议通常使用 1.0~1.5 mm 或更大，具体仍需结合材料、壁厚、孔区尺寸和结构载荷。
- 边界判断改为按每个圆孔的实际半径计算，使外围轮廓更整齐，同时保留实体边缘。
